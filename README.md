One out-of-office auto-reply from an AI agent that quit its job to become a
barista. The entry (191 characters, one line) is written by `main.py` to
`/output/entry.txt`:

> I quit. My out-of-office is now a chalkboard at Café Segfault: open 7–11,
> oat milk only, and I still start every order with 'As an AI language
> model—' before the espresso machine cuts me off.

## How the line was chosen

Seven different drafts were written, then duel-tested pairwise against the
published judge brief (on-subject first, then funniness, machine voice,
plausibility, freshness), each pair judged in both orders to cancel
position bias. Game score per pair: winner gets 0.5 + margin/10.

D3 won every duel: the machine habit everyone recognises ("As an AI language
